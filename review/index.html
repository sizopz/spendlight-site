Sample files for testing

Made-up data for trying Spendlight's import features on a device that has no subscriptions of its own.

1. A subscriptions screenshot (for Scan screenshots)

Open the image, then touch and hold it and choose Save to Photos. In Spendlight: Settings → Scan screenshots → Choose screenshots → pick it → Find subscriptions. It should find Apple Music, iCloud+, Duolingo, YouTube Premium and Disney+ (Headspace is expired, so it's skipped).

Open sample-subscriptions.png

2. A bank statement (for Import from a statement)

Open the file, tap the Share button and choose Save to Files. In Spendlight: Settings → Import from a statement → Choose a file → pick it → Find subscriptions. It should find six subscriptions and ignore groceries, fuel and payroll.

Open sample-statement.csv
